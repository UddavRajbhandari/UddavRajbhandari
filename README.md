## 📌 Featured Project

### [Production RAG Pipeline](https://github.com/UddavRajbhandari/Production-RAG)
End-to-end RAG system with hybrid retrieval, LangGraph multi-agent reasoning, guardrails, and RAGAS evaluation.

| Capability | Implementation |
|---|---|
| Ingestion | PDF/DOCX/XLSX parser → structure-aware chunking → metadata enrichment |
| Storage | Qdrant (dense) + BM25 (sparse) + Neon/Postgres (metadata) |
| Retrieval | Hybrid search + ONNX cross-encoder reranking |
| Reasoning | 8-node LangGraph chain with conditional routing |
| Guardrails | PII masking, semantic cache, token budget, prompt hardening |
| Validation | Gatekeeper + Auditor + Strategist human validation nodes |
| Evaluation | RAGAS (faithfulness, relevancy, precision, recall, completeness) |
| Frontend | Next.js with streaming responses, session management, settings |
| Deployment | Docker, GitHub Actions CI/CD, Vercel + HF Spaces |
